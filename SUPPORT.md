# Support

Stratigraphic Amenity is community-supported software.

## Get Help

Before asking for help, check the README, maintained documentation, existing
issues, and existing discussions. Then use:

* [GitHub Discussions](https://github.com/EigenformAI/stratigraphic-amenity/discussions)
  for installation questions, usage help, MCP integration, and design
  discussion.
* [Bug reports](https://github.com/EigenformAI/stratigraphic-amenity/issues/new?template=bug.yml)
  for reproducible defects in supported, publicly available functionality.
* [Feature requests](https://github.com/EigenformAI/stratigraphic-amenity/issues/new?template=feature.yml)
  for scoped proposals.

Include the package version, Python version, operating system, installation
profile, relevant configuration names with values redacted, expected behavior,
actual behavior, and a minimal reproduction. Preserve warnings and provenance
because an empty provider response can indicate missing coverage rather than
absence of geologic data.

Do not post credentials, private maps, sensitive paths, or confidential
provider results. Report suspected vulnerabilities privately according to
[SECURITY.md](SECURITY.md). Report conduct concerns through the private channel
in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Scope

Maintainers prioritize the latest supported release on Python 3.11. Support is
best-effort; no response-time or compatibility guarantee is provided.

The following are outside the supported public release:

* Private or locally modified models and datasets outside the attributed asset installer
* Live third-party service availability, correctness, quotas, or credentials
* Custom remote exposure of the local stdio MCP server
* General geological interpretation or validation of model-generated answers

Questions about a third-party service or dataset may need to be directed to
that provider.
